# Игра "Угадай число"

Простая консольная игра, в которой игроку нужно угадать случайное число за ограниченное количество попыток. 

## Особенности реализации
В проекте реализовано базовое ТЗ и все 8 дополнительных фич:
- Защита от некорректного ввода (буквы, пустые строки, выход за пределы диапазона не тратят попытки).
- Подсказки по расстоянию (Горячо, Тепло, Холодно).
- Вывод истории попыток на каждом шаге.
- Три уровня сложности.
- Возможность сыграть повторно без перезапуска приложения.
- Сохранение истории игр (победы/проигрыши, даты, количество попыток) в файл `results.json`.
- Чистая архитектура (логика разделена на независимые функции).
- Цветовое оформление вывода в терминале через ANSI-коды.

## Требования
- Установленный Go версии 1.20 или выше.

## Как запустить
```bash
go run main.go
```
